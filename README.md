# そろばんクラフト

こども向けの「フラッシュ暗算」「よみあげ暗算」「よみあげそろばん」「そろばん」「ドライブモード」専用トレーニングアプリです。マインクラフト風のドット文字・ベベルUIで遊べます。

## あそべること

- **フラッシュ暗算**：数字が画面に次々と表示され、たし算・ひき算した合計を入力する
- **よみあげ暗算**：数字を音声で読み上げる（画面には数字を出さない）。合計を入力する。
  読み上げは伝統的な読み上げ算の言い回し「ねがいましては → ◯円なり → …… → ◯円では」に従う。
  引き算に変わる時は「引いては」、足し算に戻る時は「加えて」を、それが かかる数字の**前**に
  1回だけ宣言し、次の宣言があるまでの数字はすべてその演算で計算する。
  また、実際の読み上げ算と同じく、計算の途中で合計がマイナスになる問題は出題しない
- **よみあげそろばん**：よみあげ暗算と同じく数字を音声で読み上げるが、頭の中ではなく
  実際のそろばんで計算してからこたえを入力する(1問ごとに読み上げ→そろばんで計算→
  キーパッドで入力、というよみあげ暗算と同じ流れ)。5級だけ加算のみ、4級以上は加減算
- **そろばん**：実際のそろばん・紙で計算しながら遊ぶモード。アプリは問題の表示とタイマー
  だけを受け持ち、答えの入力はしない。問題には「N問目」の番号を大きく表示し、「つぎへ／
  もどる」ボタンで問題を見て回って紙にこたえを書いていく(種目が切り替わっても待ち時間・
  演出は入れず即座に次の問題を出す、1秒を争う競技のため)。最後の問題まで進むか、時間切れ
  になったタイミングで、紙に書いたこたえを まとめて入力する画面が出る。全級とも見取り算
  10問+かけ算20問+わり算20問の計50問を、まとめて30分で通しで測る(答え入力は最後に1回)。
  採点は見取り算1問10点・かけ算/わり算1問5点(満点300点)で、合計8割以上の得点で合格。
  問題の桁数・小数の有無は日本商工会議所 珠算能力検定試験の実際の出題形式を踏襲している
- **ドライブモード**：車の運転中など画面を見られない状況向けのモード。問題を読み上げたあと、
  少し間をおいて答えも読み上げる(耳だけで正誤を確認できる)。答えの入力・採点はなく、
  「とめる」を押すまで問題を無限に出しつづける。級・難易度はよみあげ暗算とまったく同じ設定を
  そのまま使う
- **級レベル**：フラッシュ暗算は7級〜1級に加えて、1級よりさらにむずかしい「初段〜5段」も
  選択可能(そろばん教室の段位表を再現)。よみあげ暗算・よみあげそろばんはどちらも6級〜1級を
  選択可能。そろばんモードは5級〜1級に加えて、4級と3級・3級と2級・2級と1級の間にはさまる
  中間級「準3級・準2級・準1級」も選択できる(そろばんモードのみ)。級が上がるほど桁数・口数
  (項の数)が増え、表示/読み上げが速くなる(モードごとに級ごとの桁数・口数・速さをそれぞれ
  別に設定している)
- フラッシュ・よみあげ・よみあげそろばんは1回のプレイ10問固定
  (3級のみ加算のみ5問+加減算5問をシャッフルして出題)
- 級ごとに合格ライン(正解数・正答率)を設定。合格するとごほうびアイテムパックを開封でき、
  全101種類(コモン〜レジェンドの5段階)のアイテムからランダムで1つ手に入る。
  挑戦した**級がむずかしいほど**・**正答率が高いほど**、レア・エピック・レジェンドなどの
  上位レアリティが出やすくなる。さらに**よみあげ暗算・よみあげそろばんはフラッシュ暗算より
  上位レアリティが格段に出やすい**(同じ級・同じ正答率でも、エピック以上の出現率がフラッシュの
  だいたい2.5〜3倍になるよう調整)
- 自己ベストスコア・プレイ記録は端末の localStorage に保存
- きろく画面では合否・得点・そろばんモードの種目別内訳を一覧表示。「CSVでダウンロード」
  ボタンで、これまで出題したすべての問題と正しい答えを「問題,答え」の2列だけのCSVファイル
  (UTF-8 BOM付き、Excel対応)としてダウンロードでき、AIなどでの分析にそのまま使える

## 動かし方

ビルド不要の素のHTML/CSS/JavaScriptです。ブラウザで `index.html` を開くか、ローカルサーバーで配信してください。

```bash
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

よみあげ暗算は Web Speech API (`speechSynthesis`) を使用するため、対応ブラウザ（Chrome, Edge など）でご利用ください。

## ファイル構成

- `index.html` — 画面構成
- `css/style.css` — マインクラフト風スタイル
- `js/levels.js` — 級ごとの難易度設定
- `js/problem.js` — 問題(数列)生成ロジック
- `js/audio.js` — 効果音(WebAudio)とよみあげ(SpeechSynthesis)
- `js/app.js` — 画面遷移・ゲーム進行のメインロジック
