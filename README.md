# そろばんクラフト

こども向けの「フラッシュ暗算」「よみあげ暗算」「そろばん」専用トレーニングアプリです。マインクラフト風のドット文字・ベベルUIで遊べます。

## あそべること

- **フラッシュ暗算**：数字が画面に次々と表示され、たし算・ひき算した合計を入力する
- **よみあげ暗算**：数字を音声で読み上げる（画面には数字を出さない）。合計を入力する
- **そろばん**：実際のそろばん・紙で計算しながら遊ぶモード。アプリは問題の表示とタイマー
  だけを受け持ち、答えの入力はしない。「つぎへ／もどる」ボタンで問題を見て回り、紙に
  こたえを書いていく。最後の問題まで進むか、時間切れになったタイミングで、紙に書いた
  こたえを まとめて入力する画面が出る。5級・4級は見取り算・かけ算・わり算をそれぞれ
  10分ずつ測り(種目ごとに答え入力→採点してから次の種目へ)、全種目7割以上正解で合格。
  3級以上は見取り算・かけ算・わり算をまとめて30分で通しで測り(答え入力は最後に1回)、
  合計8割以上正解で合格
- **級レベル**：フラッシュ暗算は6級〜1級、よみあげ暗算・そろばんは5級〜1級を選択可能。
  級が上がるほど桁数・口数(項の数)が増え、表示/読み上げが速くなる
  (モードごとに級ごとの桁数・口数・速さをそれぞれ別に設定している)
- フラッシュ・よみあげは1回のプレイ10問固定(3級のみ加算のみ5問+加減算5問をシャッフルして出題)
- 級ごとに合格ライン(正解数・正答率)を設定。合格するとごほうびアイテムパックを開封できる
- 自己ベストスコア・プレイ記録は端末の localStorage に保存
- きろく画面では合否・正答率・そろばんモードの種目別内訳を一覧表示。「CSVでダウンロード」
  ボタンで全プレイ記録をCSVファイル(UTF-8 BOM付き、Excel対応)としてダウンロードでき、
  AIなどでの分析にも使える

フラッシュ暗算の級ごとの目安（そろばん教室の実際の級位表(2桁固定・級ごとの口数と制限時間)を再現したもの）：

| 級  | 桁数 | 口数 | 制限時間 |
|-----|------|------|----------|
| 6級 | 2桁  | 3口  | 6秒      |
| 5級 | 2桁  | 4口  | 7秒      |
| 4級 | 2桁  | 5口  | 7.5秒    |
| 3級 | 2桁  | 10口 | 15秒     |
| 2級 | 2桁  | 10口 | 10秒     |
| 1級 | 2桁  | 10口 | 8秒      |

よみあげ暗算の級ごとの目安（トレーニング用設定であり、公式の検定基準ではありません）：

| 級  | 桁数   | 口数 | 問題数                    | 合格ライン |
|-----|--------|------|---------------------------|-----------|
| 5級 | 1〜2桁 | 7口  | 10問                       | 7問正解    |
| 4級 | 2桁    | 7口  | 10問                       | 7問正解    |
| 3級 | 2桁    | 10口 | 加算のみ5問+加減算5問(混合) | 7問正解    |
| 2級 | 2〜3桁 | 10口 | 10問                       | 8問正解    |
| 1級 | 3〜4桁 | 10口 | 10問                       | 8問正解    |

そろばんモードの級ごとの目安（わり算は「わる数の桁数÷商の桁数」）：

| 級  | 見取り算      | かけ算       | わり算(わる数÷商) | 測り方・合格ライン |
|-----|---------------|--------------|-------------------|-------------------|
| 5級 | 2桁×5口 10問   | 2桁×1桁 10問  | 1桁÷2桁 10問       | 種目ごとに10分/7割以上 |
| 4級 | 2桁×6口 10問   | 2桁×2桁 10問  | 1桁÷3桁 10問       | 種目ごとに10分/7割以上 |
| 3級 | 2桁×10口 10問  | 3桁×2桁 20問  | 2桁÷3桁 20問       | 全種目まとめて30分/合計8割以上 |
| 2級 | 3桁×10口 10問  | 3桁×3桁 20問  | 2桁÷4桁 20問       | 全種目まとめて30分/合計8割以上 |
| 1級 | 4桁×10口 10問  | 4桁×3桁 20問  | 3桁÷4桁 20問       | 全種目まとめて30分/合計8割以上 |

## 動かし方

ビルド不要の素のHTML/CSS/JavaScriptです。ブラウザで `index.html` を開くか、ローカルサーバーで配信してください。

```bash
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

よみあげ暗算は Web Speech API (`speechSynthesis`) を使用するため、対応ブラウザ（Chrome, Edge など）でご利用ください。

## ファイル構成

- `index.html` — 画面構成
- `css/style.css` — マインクラフト風スタイル
- `js/levels.js` — 級ごとの難易度設定
- `js/problem.js` — 問題(数列)生成ロジック
- `js/audio.js` — 効果音(WebAudio)とよみあげ(SpeechSynthesis)
- `js/app.js` — 画面遷移・ゲーム進行のメインロジック
