# そろばんクラフト

こども向けの「フラッシュ暗算」「よみあげ暗算」専用トレーニングアプリです。マインクラフト風のドット文字・ベベルUIで遊べます。

## あそべること

- **フラッシュ暗算**：数字が画面に次々と表示され、たし算・ひき算した合計を入力する
- **よみあげ暗算**：数字を音声で読み上げる（画面には数字を出さない）。合計を入力する
- **級レベル**：フラッシュ暗算は6級〜1級、よみあげ暗算は5級〜1級を選択可能。級が上がるほど
  桁数・口数(項の数)が増え、表示/読み上げが速くなる
  (フラッシュ暗算とよみあげ暗算は級ごとの桁数・口数・速さをそれぞれ別に設定している)
- 1回のプレイは10問固定(3級のみ加算のみ5問+加減算5問をシャッフルして出題)
- 級ごとに合格ライン(正解数)を設定。合格するとごほうびアイテムパックを開封できる
- 自己ベストスコア・プレイ記録は端末の localStorage に保存

フラッシュ暗算の級ごとの目安（そろばん教室の実際の級位表(2桁固定・級ごとの口数と制限時間)を再現したもの）：

| 級  | 桁数 | 口数 | 制限時間 |
|-----|------|------|----------|
| 6級 | 2桁  | 3口  | 6秒      |
| 5級 | 2桁  | 4口  | 7秒      |
| 4級 | 2桁  | 5口  | 7.5秒    |
| 3級 | 2桁  | 10口 | 15秒     |
| 2級 | 2桁  | 10口 | 10秒     |
| 1級 | 2桁  | 10口 | 8秒      |

よみあげ暗算の級ごとの目安（トレーニング用設定であり、公式の検定基準ではありません）：

| 級  | 桁数   | 口数 | 問題数                    | 合格ライン |
|-----|--------|------|---------------------------|-----------|
| 5級 | 1〜2桁 | 7口  | 10問                       | 7問正解    |
| 4級 | 2桁    | 7口  | 10問                       | 7問正解    |
| 3級 | 2桁    | 10口 | 加算のみ5問+加減算5問(混合) | 7問正解    |
| 2級 | 2〜3桁 | 10口 | 10問                       | 8問正解    |
| 1級 | 3〜4桁 | 10口 | 10問                       | 8問正解    |

## 動かし方

ビルド不要の素のHTML/CSS/JavaScriptです。ブラウザで `index.html` を開くか、ローカルサーバーで配信してください。

```bash
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

よみあげ暗算は Web Speech API (`speechSynthesis`) を使用するため、対応ブラウザ（Chrome, Edge など）でご利用ください。

## ファイル構成

- `index.html` — 画面構成
- `css/style.css` — マインクラフト風スタイル
- `js/levels.js` — 級ごとの難易度設定
- `js/problem.js` — 問題(数列)生成ロジック
- `js/audio.js` — 効果音(WebAudio)とよみあげ(SpeechSynthesis)
- `js/app.js` — 画面遷移・ゲーム進行のメインロジック
